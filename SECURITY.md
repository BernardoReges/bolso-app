# Dados e segurança

Este projeto não oferece conexão com instituição financeira e não usa credenciais bancárias. Não envie extratos, backups reais, senhas ou chaves de assinatura em issues e pull requests.

Os registros são locais e o backup JSON não é criptografado. O aplicativo não implementa recuperação remota. Caso encontre uma falha, descreva-a com uma base fictícia e sem dados de terceiros. Evite publicar um exemplo que exponha informações pessoais.

Uma atualização do aplicativo deve preservar o identificador Android, o formato de armazenamento e a chave de assinatura. Chaves de build devem ficar fora do repositório público.
